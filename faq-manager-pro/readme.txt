=== FAQ Manager Pro ===
Version: 1.0.0
Requires at least: 5.8
License: GPLv2 or later

FAQ manager: write FAQs once, attach them to any public post type (including ACF / CPT UI types).

== Installation ==
1. Copy the faq-manager-pro folder to wp-content/plugins and activate.
2. FAQs > Add new to write FAQs (category optional, "Archive" checkbox available).
3. Edit any post/page/CPT item: use the "FAQs for this content" box to write new FAQs and/or search and add existing (archived too) ones; drag to reorder.
4. Put [faq_manager] in the single template/content. Attributes: post_id, category, limit, schema, open (first|all|none), multiple.
5. FAQs > Appearance to customize design with live preview. FAQs > Settings to pick post types.
